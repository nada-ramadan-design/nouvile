## 📸 About the Project

Nouvile is a creative front-end web project inspired by the beauty and mystery of the night sky.

The website transforms a simple scrolling experience into an interactive journey through a magical landscape. Different layers move at different speeds, creating a parallax effect that adds depth and movement to the scene.

## 🎨 Features

- 🌌 Layered night landscape
- 🌙 Moonlight and mountain scenery
- ⛵ Animated boat movement
- ✨ Parallax scrolling effects
- 🎭 Dynamic title and background transitions
- 📱 Responsive layout for different screen sizes
- 🪄 Smooth animations and interactive hover effects

## 🛠️ Technologies Used

- HTML5 — Website structure
- CSS3 — Styling, layouts, and animations
- JavaScript — Scroll interactions and dynamic effects

## 🚀 Run Locally

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Make sure all image files are inside the `images` folder.
4. Open `index.html` using Live Server or your browser.
